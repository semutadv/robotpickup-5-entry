One pickup line, written for the make.fun bounty "Robot Romance",
aimed at a machine: it compares the robot to a software update,
because every time one appears, the human stops everything and agrees
to whatever it wants. Flattery, delivered as a confession.

## Running it

`node main.ts` clears the output directory's contents and writes the
line to `/output/entry.txt` as plain UTF-8 text.
